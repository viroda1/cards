# Graded Math · Levels

A clean, visual website that organizes mathematics topics by grade level — from early counting to calculus and beyond. Built with a soft, modern aesthetic using cards and subtle blur effects.

![screenshot placeholder](https://via.placeholder.com/800x400?text=Graded+Math+Preview)

## ✨ Features

- **Grade-by-grade organization** — K–12 mapped to core topics
- **Visual card layout** — each level shows key concepts at a glance
- **Beyond high school** — includes calculus, statistics, linear algebra
- **Responsive grid** — adapts from mobile to desktop
- **Soft, accessible design** — pastels, gentle shadows, readable typography

## 🧮 Topics covered

| Level | Focus areas |
|-------|-------------|
| K–5 | Counting, operations, fractions, geometry basics |
| 6–8 | Ratios, expressions, linear equations, pre-algebra |
| 9–12 | Algebra I & II, geometry, pre-calculus |
| Advanced | Calculus, statistics, linear algebra |

## 🛠️ Built with

- HTML5
- CSS3 (Grid, Flexbox, backdrop-filter)
- [Inter font](https://fonts.google.com/specimen/Inter) (system fallback)

## 🚀 Getting started

1. Clone or download the HTML file
2. Open in any modern browser
3. No build steps — it's static HTML/CSS

```bash
curl -O https://example.com/graded-math.html
open graded-math.html
```

## 📁 Structure

The entire site is a single HTML file with inline styles. No external dependencies.

```
graded-math.html
├── header with grade pill
├── responsive card grid (17 levels)
├── extra row for college topics
└── footer with legend
```

## 🎨 Design notes

The style follows a consistent theme:
- **Cards** — white with translucent background, border, hover lift
- **Typography** — clean, weight-balanced, blue-undertones
- **Colors** — soft blues, grays, touches of accent via emoji
- **Blur effects** — subtle backdrop filters for depth
